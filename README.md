# Markov Chain Sound Graph

마르코프 체인으로 소리를 잇는 장난감. 노드마다 짧은 소리 클립을 넣고 간선에 확률을 주면, 워커들이 그래프를 돌아다니며 소리를 재생한다.

빌드도, 서버도, 의존성도 없다. `index.html` 하나를 브라우저로 열면 끝.

## 실행

```
# 파일을 그냥 열어도 되고
xdg-open index.html

# 로컬 서버로 열고 싶다면
python3 -m http.server 8000   # http://localhost:8000
```

Chromium 계열 기준으로 만들었다. 소리는 사용자 조작(클릭) 이후에만 재생되므로, 시작 버튼을 누르면 바로 들린다.

## 쓰는 법

| 하고 싶은 것 | 조작 |
| --- | --- |
| 노드 추가 | 빈 캔버스 더블클릭 (또는 배경 우클릭 → 노드 추가) |
| 연결 추가 | 노드를 **Shift+드래그**해서 다른 노드 위에 놓기 (자기 자신에 놓으면 자기 자신으로 돌아오는 간선) |
| 노드 이동 | 드래그 |
| 소리 넣기 | 노드 더블클릭, 또는 오디오 파일을 노드 위에 드롭 |
| 노드 메뉴 | 노드 우클릭 — 이름 바꾸기, 색, 소리, 중력/repel, 고정, 시작 노드, 삭제 |
| 간선 메뉴 | 간선 우클릭 — 확률 슬라이더, 삭제 |
| 확률 조절 | 간선 위에서 휠 (±1%, Shift+휠 ±10%) |
| 시작 / 정지 | 좌하단 아이콘 버튼 또는 `Space` |
| 삭제 | 선택 후 `Del` / `Backspace` |
| 이름 바꾸기 | 선택 후 `F2` |
| 전체 설정 | 배경 우클릭 — 워커 수, 시작 방식, 소리 사이 딜레이, 중력, 저장/불러오기/비우기 |

## 동작 방식

- 워커가 노드에 도달하면 그 노드의 소리를 재생하고, **소리가 끝난 뒤에** 다음 간선을 추첨한다. 간선 이동 애니메이션은 연출일 뿐이라 소리를 붙잡지 않는다.
- 확률은 **퍼센트**다. 한 노드에서 나가는 간선의 합은 항상 100이고, 하나를 올리면 나머지가 기존 비율을 유지한 채 줄어든다. 나가는 간선이 하나뿐이면 100% 고정.
- 워커는 여러 개 동시에 돌 수 있고(1~9), 각자 독립적으로 움직이며 소리가 겹친다.
- 소리 사이 딜레이(0~2초)를 두면 클립 사이에 쉼이 생긴다.
- 중력은 배치 도구다. 켜면 노드가 감쇠하며 정착하고 스스로 멈춘다. 노드별로 gravity/repel을 줄 수 있고, "중력 무시 (고정)"를 켠 노드는 화면상 제자리에 남는다.

## 저장

- 작업 중인 그래프는 IndexedDB에 자동 저장된다. 새로고침해도 유지되고, 일부러 비운 그래프는 다시 채워지지 않는다.
- 파일로 저장하면 JSON 하나(`markov-sound-graph-*.json`)가 나온다. 오디오는 base64 데이터 URL로 그 안에 들어 있어서, 이 파일 하나로 다른 브라우저에서도 그대로 복원된다.
- 오디오 파일 하나당 8MB까지.

## 셀프테스트

```
index.html?selftest=1
```

페이지가 그래프 로직(확률 추첨, 퍼센트 불변식, 직렬화/역직렬화, 곡선 기하, 히트 테스트, 물리)을 검사하고 결과를 화면에 찍는다. 전부 통과하면 `ALL PASSED`.

헤드리스로 돌리려면:

```
chromium --headless --dump-dom "file://$PWD/index.html?selftest=1" | grep -E "FAIL|PASSED"
```

## 구현 노트

- 단일 파일: `index.html` (바닐라 HTML/JS/CSS). 빌드·의존성 없음.
- 오디오는 Web Audio API. 디코드 결과는 메모리 캐시, 깨진 파일은 한 번만 경고하고 조용히 넘어간다.
- 폰트는 [Jua](https://fonts.google.com/specimen/Jua) (Google Fonts). 오프라인이면 시스템 폰트로 폴백한다.
- 모든 간선은 이차 베지어 곡선이다. 자기 자신으로 가는 간선도 같은 방식이라, 그 노드에서 가장 비어 있는 방향으로 부푼다. 퍼센트 칩은 곡선 바깥에 붙어 있고 그 자체가 클릭 영역이다.
- 화면 배율·창 크기가 바뀌면 캔버스를 다시 잰다. 그래프는 불러올 때 한 번 화면에 맞춰지고, 그 뒤로는 카메라가 움직이지 않는다(팬·줌 없음).
